### Phase 1 — what changed

- **A1** `--text-muted` `#65748a` → **`#5f6e85`** in `index.css` (light only; dark `#93a5ba`
  already passed at 6.61:1). One step, chosen by search (`scratch/contrast_candidates.py`)
  as the smallest darkening that clears 4.5:1 on the page background while staying visibly
  lighter than `--text-secondary`. Blast radius checked: the token is read by the analytics
  module (`.subtle`, `--chart-axis`), `Input.jsx` icon, `.input::placeholder`,
  `.field-control::placeholder`, and two dark-only rules that use the dark value. Every use
  is text/icon on a light surface, so all of them improve and none regress.
  Also: `.meta` 11px → 12px (the meta floor), and the reach footnote `text-[11px]
  styles.subtle` → `text-xs styles.secondary`.
- **A2** `MapFilterRail` zero-count tabs: removed the `opacity-60` that was applied to the
  WHOLE tab (it read as disabled although nothing is disabled), kept the label at full
  contrast, and moved the muting to the count alone — `text-gray-400` (2.54:1, failed AA) →
  `text-gray-500` (4.83:1) — and raised the count 10px → 12px.
- **A3** `title` added to the notification bell (had `aria-label`, no `title`) and to all
  four month/year stepper chevrons. Map tool buttons already had both plus a 44px hit area
  (`before:-inset-2`) around a 28px visual. The workspace focus rule now uses
  `var(--focus-ring)` instead of the accent, so this page's ring is the same token as the
  rest of the app.
- **T1** page title `sm:text-[30px]` → `sm:text-[28px]` (mobile stays 26px); card title
  `.title` 17px → 16px.
- **T2** `.metricValue` already had `font-variant-numeric: tabular-nums`; a **zero** KPI now
  drops one step (`styles.secondary`) instead of shouting, and the amber pending value is
  exempt so it stays the strongest number on the row.
